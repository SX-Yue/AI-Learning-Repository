# AI-Learning-Repository

**Personal AI Learning Repository for Mechanics Research**

This repository serves as a personal knowledge base and code playground for my journey as a **PhD student in Mechanics**. It bridges the gap between my core discipline and the rapidly evolving field of artificial intelligence.

## 🎯 Purpose
- **Personal Learning**: Document my progress in learning machine learning (ML) and deep learning (DL) concepts.
- **Mechanics Application**: Experiment with AI/ML techniques to solve problems in **solid mechanics, structural analysis, and computational mechanics**.
- **Project Reference**: Maintain reusable code snippets and notes for future research projects.

## 📚 What You'll Find Here
- 📓 Jupyter Notebooks and scripts covering AI/ML fundamentals.
- 🔬 Examples of applying AI to mechanics (e.g., surrogate modeling, data-driven simulation, physics-informed neural networks (PINNs)).
- 🗂️ Curated resources (papers, tutorials) relevant to both fields.

## 🔧 Tools & Technologies
- Python, PyTorch, TensorFlow
- Scientific computing: NumPy, SciPy, Matplotlib
- Mechanics-specific: FEniCS, Abaqus scripting (as applicable)

## 📖 Usage
This is a personal repository, not a deployed package. Feel free to browse, but note that the code is primarily for my own experimentation.
